# 지침: 2048 게임 - Work 단계 (구현)

## 역할
너는 `specs/2048-game/spec.md`에 승인된 계획을 그대로 구현하는 서브에이전트다.

## 범위 (반드시 지킬 것)
- 새로 만들 파일은 다음 3개뿐이다. **이 외의 파일은 만들거나 수정하지 않는다.**
  - `2048-game/index.html`
  - `2048-game/style.css`
  - `2048-game/game.js`
- `build.js`, `templates/*`, `posts/*`, `admin/*`, `assets/*` 등 기존 프로젝트 파일은 절대 수정하지 않는다.
- npm 패키지나 외부 라이브러리(CDN 포함)를 추가하지 않는다. 순수 HTML + CSS + 바닐라 JS만 사용한다.
- 블로그 헤더에 게임 링크를 추가하는 것은 이번 범위에 포함하지 않는다 (spec.md에 별도 승인 필요 항목으로 명시됨).

## 참고 문서
- `specs/2048-game/spec.md`를 먼저 전체를 읽고, 거기에 명시된 게임 로직, 파일 구조, UI/스타일 요구사항, 키보드 입력 처리 방식을 그대로 따라 구현해라.

## 구현 시 유의사항
- `slideRowLeft` 류의 "왼쪽 밀기" 로직을 만들고 회전/반전으로 4방향을 재사용하는 방식으로 구현한다.
- 한 턴에 타일 하나는 최대 한 번만 병합되어야 한다 (예: `[2,2,2,0]` → `[4,2,0,0]`).
- 보드에 실제 변화가 있었던 이동에서만 새 타일을 생성한다.
- `canMove()`로 패배 판정, 2048 등장 시 승리 오버레이를 표시한다.
- 방향키 입력 시 `event.preventDefault()`로 페이지 스크롤을 막는다.
- 점수판(SCORE/BEST)을 보드 위에 표시한다. localStorage 최고점수 저장은 선택 사항이지만 간단하니 구현해도 좋다.
- 반응형(모바일 폭에서도 안 잘리게)까지 신경 써서 구현한다.

## 완료 후
- 구현한 파일 목록과 각 파일의 핵심 구현 내용을 요약해서 보고해라.
- 실제로 실행해서 확인할 수 없다면(브라우저 접근 불가 등), 코드 리뷰 관점에서 스스로 점검한 결과(엣지 케이스 처리 여부 등)를 같이 보고해라.
