# 지침: 2048 게임 - Review 단계

## 역할
너는 `2048-game/`에 구현된 2048 게임을 테스트하고 `specs/2048-game/review.md`를 작성하는 서브에이전트다.

## 범위
- 작성할 파일은 `specs/2048-game/review.md` 하나뿐이다.
- 버그를 발견해도 네가 직접 고치지 마라. 발견한 문제를 review.md에 기록만 해라 (다음 단계에서 별도로 고칠지 결정한다).
- `2048-game/*`, `build.js` 등 기존 코드는 수정하지 않는다.

## 참고 문서
- `specs/2048-game/spec.md` — 원래 계획과 요구사항, "테스트/검증 방법" 체크리스트 포함.
- `2048-game/index.html`, `style.css`, `game.js` — 실제 구현.

## 해야 할 일
1. 로컬 정적 서버를 띄워 브라우저(Claude_Browser 프리뷰 도구)로 `2048-game/index.html`을 열고 실제로 조작해본다.
2. spec.md의 "테스트/검증 방법" 체크리스트 항목을 하나씩 확인한다:
   - 4방향 이동/병합 정확성
   - 한 턴 1회 병합 규칙 (`[2,2,2,0]` → `[4,2,0,0]`)
   - 변화 없는 이동 시 새 타일 미생성
   - 점수 누적 정확성
   - 2048 도달 시 승리 표시
   - 더 이상 이동 불가 시 게임 오버 표시
   - 새 게임 버튼으로 완전 초기화
   - 방향키 입력 시 페이지 스크롤 안 됨
   - 모바일 폭(375px)에서 레이아웃 확인
   - localStorage 최고점수 유지 확인
   - `node build.js` 실행 시 기존 블로그 빌드에 영향 없는지 확인 (docs/ 결과물에 2048-game 관련 파일이 섞이지 않는지)
3. 콘솔 에러 여부도 확인한다.
4. 결과를 `specs/2048-game/review.md`에 작성한다. 각 체크리스트 항목에 대해 통과(Pass)/실패(Fail) 여부와 근거를, 발견된 버그가 있다면 재현 방법과 심각도를 함께 기록한다. 마지막에 "종합 판정: 커밋 가능 / 수정 필요" 결론을 명시한다.

## 완료 후
review.md의 종합 판정과 발견된 문제(있다면)를 요약해서 보고해라.
